# Responsive Card Using HTML & CSS 🎴

A simple responsive card layout built with **HTML and CSS**. The project includes image cards, author details, category badges, hover effects, and a responsive flexbox layout for different screen sizes.

## 🚀 Features

* 📱 Fully Responsive Design
* 🎨 Clean and Modern UI
* 🖼️ Images Included from Assets Folder
* 💻 Built with HTML & CSS
* ✨ Beginner-Friendly Project

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Card-using-html-or-css-/
│
├── index.html
├── style.css
├── README.md
│
└── Assets/
    ├── Ul Ux.avif
    ├── video editing.avif
    ├── full-stack .webp
    └── author images
```

## 🖼️ Images

All images used in this project are stored in the **Assets folder** and are used inside the responsive cards.

## 💡 What I Learned

Through this project, I practiced:

* HTML structure
* CSS styling
* Responsive design
* Flexbox
* Responsive Flexbox layout
* Creating responsive cards
* Using images from an Assets folder

## 🖥️ How to Use

1. Clone this repository:

```bash
    git clone https://github.com/fizabaneen/Card-using-html-or-css-.git
```

2. Open the project folder.

3. Make sure the **Assets** folder remains in the project directory.

4. Open `index.html` in your browser.
